## Selected Projects
### 1. Self-Balancing Robot
Development of a self-balancing robot based on Arduino Uno utilizing a MPU6050 for real-time tilt measurement and feedback control. The system integrates a L298N to drive DC motors powered by 18650 lithium-ion battery cells. Balance stabilization is achieved through a PID controller, with parameter tuning performed using the Ziegler–Nichols method (Type II) to optimize system response. The project demonstrates closed-loop control implementation, sensor data processing, and real-time embedded system integration for dynamic stability.

### 2. 100-Ton Fender Testing Machine
100-ton PIANC-standard Fender Testing Machine at PT Robo Marine Indonesia is project focused on developing an integrated measurement system capable of accurately acquiring and recording key testing parameters, including reaction force, hydraulic pressure, and deflection during fender compression tests. My work involved system block diagram development, sensor and component selection, PCB design, hardware integration, calibration, and functional testing. The system utilized load cells, pressure sensors, a draw-wire sensor, a backup ultrasonic sensor, a 24-bit ADC, and a Raspberry Pi for data acquisition and transmission to a PC-based data logger interface. This project supported the transition from conventional, partially manual testing methods to a more reliable, continuous, and industry-oriented testing system for evaluating fender performance in maritime applications.

### 3. Geophysical Measurement DeviceDevelopment of a geoelectrical measurement instrument for characterizing the electrical properties of subsurface rock formations. The system operates by injecting current into the ground through two current probes and measuring the resulting potential difference through two voltage probes to support geophysical investigation and subsurface analysis. The instrument was designed with several main functional blocks, including an interface block for user interaction, a switching block for probe path selection, an injector block for current delivery, a sensing block for voltage measurement and signal acquisition, and an MCU block for system control, data processing, and overall coordination of the measurement process.
